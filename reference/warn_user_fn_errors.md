# Emit the collected user-code failures as a single warning

Emit the collected user-code failures as a single warning

## Usage

``` r
warn_user_fn_errors(entries)
```

## Arguments

- entries:

  List of entries recorded by
  [`record_user_fn_error()`](https://atorus-research.github.io/tplyr2/reference/record_user_fn_error.md)

## Value

Invisible NULL
